# 🍎 Food Eater Game

A webcam-controlled food eating game made with Python,
Pygame and MediaPipe.

## 🎮 How to play

1. Start the game.
2. Allow webcam access.
3. Move your face to control the game.
4. Open your mouth to eat the falling food.
5. Avoid bombs.
6. Collect bonus food to increase your score.
